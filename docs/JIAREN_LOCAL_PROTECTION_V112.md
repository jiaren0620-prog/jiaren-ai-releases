# Jiaren AI v1.1.2 本地功能保护

## 已实施

- 完整前端保存在 `app.asar`，不再复制到 `app.asar.unpacked/dist`。
- Electron Builder 将 ASAR 哈希写入 Windows 可执行文件的完整性资源。
- 生产窗口关闭 DevTools，并拦截调试快捷键、弹窗和非可信页面跳转。
- 本地 HTTP 服务使用每次启动随机生成的会话令牌；未授权的端口访问返回 401。
- `sharp`、ONNX、FFmpeg 等必须解包的原生运行时保持本地可用，不上传用户内容。
- 正式包禁止 source map、认证文件、Cookie、`.env` 和本地用户配置进入安装包。
- 软件许可调整为免费个人非商用、未开放源代码；第三方组件继续遵守各自许可证。

## 保护边界

ASAR、代码压缩、调试限制和本地令牌用于阻止直接浏览、随手复制和端口抓取，不能阻止有能力控制用户电脑的专业逆向人员。任何必须在用户电脑执行的代码，理论上都可能被观察。

## 下一阶段原生化候选

1. 私有提示词组合与模型路由规则。
2. 工作流模板展开、冲突处理和动作校验。
3. 右键高级图片工具的任务编排核心。
4. 发布包完整性与功能资产解密入口。

这些模块适合迁移到签名的 Rust/C++ 原生模块。画布 UI、节点协议和第三方开源组件不应混入私有原生模块，以便继续满足第三方许可证和降低升级风险。

## 性能后续

功能保护不等同于性能优化。当前运行日志仍显示 Three.js 被重复加载。后续应优先统一 Three.js 运行时、拆分 3D/肖像/视频模块的本地按需加载，并引入画布视口虚拟化和图片代理缓存。
