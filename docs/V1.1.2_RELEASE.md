# Jiaren AI V1.1.2

**AI Agent 驱动的桌面无限画布创作工作台**

[官方网站](https://win.jiaren.xyz) | [项目主页](https://github.com/jiaren0620-prog/jiaren-ai-releases) | [问题反馈](https://github.com/jiaren0620-prog/jiaren-ai-releases/issues)

发布日期：2026-08-04  
适用平台：Windows 10/11 x64

## 本版重点

- 完成本地 Codex 与 Jiaren 画布联动，对话过程、工具状态、审批和画布结果保持可见；
- Codex 图片任务只服从本地 Codex App Server 的真实能力声明，不转交无关图片模型；
- 新增图片、视频、音频多渠道驱动和配置持久化，支持用户自己的兼容接口与真实模型 ID；
- 优化多图片任务队列、参数切换、取消、失败隔离和更新下载进度；
- 新增图片标注修改流程，标注节点可保存、连接并保留修改提示词；
- 恢复图片右键完整 25 项工具，修复 SVG 下载格式、暗色菜单、节点圆角和按钮一致性；
- 优化启动页四个创作入口、安装器排版、品牌图标和免责声明确认流程；
- 保留本地抠图、Upscayl、FFmpeg、Seedance、Skills、Jiaren Agent、社区与画布基础功能。

1. 本软件不内置、不出售、不托管任何模型 API Key，联网生成能力由用户自行配置。
2. 安装前必须阅读并勾选免责声明。
