Jiaren AI 1.1.3 macOS x64

本版本未使用 Apple 开发者证书，也未进行 Apple 公证。
用户不需要安装 Xcode 或任何开发者工具。

首次打开：
1. 解压 ZIP。
2. 将“Jiaren AI.app”拖入“应用程序”。
3. 右键“首次打开.command”并选择“打开”；脚本会自动识别同目录或“应用程序”中的 Jiaren AI.app。
4. macOS 会使用系统自带的 xattr 与 codesign 完成本机临时授权，然后启动软件。

也可以在“系统设置 > 隐私与安全”中选择“仍要打开”。
软件不内置 API 密钥，仍使用用户自己配置的 API。
