# Writing Shape

1. Read all supplied material before drafting.
2. Preserve source facts, names, chronology, dialogue, and explicit constraints.
3. Establish audience, purpose, and required output shape.
4. Ground each concept before later sections depend on it.
5. Choose prose, lists, tables, quotes, and code blocks deliberately.
6. Name missing evidence instead of inventing it.
7. For transformations, keep the source read-only and make the output traceable to it.
8. Prefer a coherent final structure over aggressive summarization.
