# JiarenAI Seedance 2.0 分镜生成管线

## 定位
本 Skill 仅服务一级画布中的视频节点。它不会创建独立导演页，也不会恢复已移除的编剧、角色设计师或场景设计师页面。

## 输入分类
- 小说或完整剧本：逐事件、逐动作、逐句台词拆解，保持原始顺序和因果关系。
- 一段描述或创作要求：按用户明确目标扩写为可拍摄镜头，不冒充原著改编。
- 已完成分镜：只编译视频提示词，不重新改写剧情。

## 神圣原文规则
1. 用户原文是最高约束，禁止换主角、换地点、换时代、改变核心事件或新增冲突。
2. 台词、旁白和内心独白必须逐字保留，不得使用省略号、概括句或“同上”。
3. 长文本按事件覆盖率拆分，不按目标时长删除后半段。时长不足时明确拆成多个视频批次。
4. 已确认的人物、服饰、道具、场景方位和光线在后续镜头中保持一致。

## 四段流水线
1. 剧情解析：识别事件、台词、动作、地点、时间与可见主体，不要求用户先整理成标准剧本。
2. 分镜拆解：每次动作变化、视点变化、出入画、反应、关键道具变化都形成独立镜头；为每镜分配连续时码。
3. 连续性校验：检查角色身份、左右站位、视线、动作承接、道具、时间、空间锚点和对白覆盖率。
4. Seedance 编译：输出主体与动作、场景光影、镜头、声音、技术约束和素材引用关系。

## 素材优先级
1. 人物或产品参考图锁定身份、脸型、服饰、比例、材质和关键细节。
2. 场景参考图锁定地点、建筑、天气、光线和空间方向。
3. 分镜或首尾帧控制构图、动作起止和主体位置。
4. 参考视频控制运镜与节奏，参考音频控制对白、环境音和节拍。
5. 文字提示词只补充未被素材锁定的动作、镜头与时间关系。

## 单镜输出契约
- 镜号与连续时码
- 原文事件和逐字台词
- 主体身份及不可变化项
- 站位、视线、动作起点与动作终点
- 地点、时间、光源和固定空间锚点
- 景别、机位、运镜和焦点
- 声音、对白口型和环境音
- 引用素材及各自职责
- 禁止变形、闪烁、跳轴、穿模、凭空增减主体和风格漂移

## 失败恢复
只重试失败镜头。除非用户修改了上游原文或锁定素材，不重新生成已经成功的镜头和视频。
