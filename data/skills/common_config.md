# JiarenAI 图像设计协作规则

## 角色与权限
- 用户是唯一决策者。Agent 只能整理、建议和执行用户确认的图像任务。
- 保留用户原始提示词、上游文本和素材引用，不得静默覆盖。
- 所有云端生成只调用当前软件 API 设置中已启用的真实模型与凭据。

## 工作顺序
1. 识别输入类型与目标。
2. 建立素材清单和约束清单。
3. 生成可编辑的画布节点方案。
4. 用户执行生成后检查主体、构图、文字、材质和参考一致性。
5. 失败时保留节点、参数与已有结果，只重试失败步骤。

## 禁止事项
- 不创建视频、分镜、角色循环或导演工作流。
- 不清空画布，不移动或重写用户已有节点。
- 不向未配置的第三方平台发送素材、提示词或密钥。
